# 진행 보고서 v0.2.0 — 대화형 CLI 인터페이스

- 작성일: 2025-02-14
- 단계: 사용자 인터페이스 1차 구현
- 상태: 코드 구현 완료 / 실환경 테스트 필요

## 1. 목표

단일 질문 후 종료되는 테스트 방식을 개선해, 사용자가 여러 질문을 연속해서 입력할 수 있는 대화형 CLI를 구현한다.

## 2. 구현 내용

- 대화형 질문 입력 루프 추가
- `exit`, `quit`, `종료` 명령 지원
- 모델 인스턴스 재사용
- 사용자 질문과 모델 답변을 대화 이력으로 저장
- 최근 대화 이력 일부를 다음 프롬프트에 포함
- `Ctrl+D`, `Ctrl+C` 종료 처리
- 모델 오류 발생 시 CLI가 즉시 종료되지 않고 오류 메시지 출력

## 3. 관련 파일

```text
app/inference.py
scripts/chat_cli.py
```

## 4. 실행 방법

```bash
source .venv/bin/activate
python -m scripts.chat_cli
```

실행 예시:

```text
문서기반 FAQ 챗봇을 시작합니다.
종료하려면 'exit', 'quit' 또는 '종료'를 입력하세요.

질문: 문서기반 FAQ 챗봇이란 무엇인가요?
답변: ...

질문: 종료
챗봇을 종료합니다.
```

## 5. 대화 이력 처리

현재는 최근 대화 메시지 일부를 다음 프롬프트에 포함한다. 이는 10GB VRAM 환경에서 Context가 계속 증가하는 것을 방지하기 위한 제한이다.

- 최대 입력 토큰: 기본 2,048
- 최근 메시지: 최대 6개
- 최대 생성 토큰: 기본 256
